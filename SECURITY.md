# Security policy

## Supported versions

Security fixes are provided for the latest released Drift image. Before the first
public image is published, report vulnerabilities against the default branch.

## Report a vulnerability

Please do not report security vulnerabilities in public issues. Use this
repository's [private security advisory](https://github.com/Grey-Harbor/drift/security/advisories/new)
flow instead. Include the affected image tag or commit, a reproduction, and the
impact you observed.

Grey Harbor will acknowledge reports privately, coordinate a fix, and publish a
release note when the issue is resolved.
