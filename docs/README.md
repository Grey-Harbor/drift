# Drift documentation

Drift documentation follows the Diátaxis model so that learning, operating, looking up, and understanding the service remain separate.

- [Tutorials](./tutorial/getting-started.md) teach a complete first graph.
- [How-to guides](./how-to/docker.md) solve operational tasks such as Docker deployment.
- [Reference](./reference/api.md) defines API routes and the [persisted model](./reference/model.md).
- [Explanation](./explanation/retrieval.md) explains why retrieval is constrained and declarative.
