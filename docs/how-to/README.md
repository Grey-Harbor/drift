# How-to guides

Use a how-to guide when you already know the Drift basics and need to complete a specific operational or contribution task.

- [Run Drift with Docker](./docker.md) — start a pinned container image, bootstrap a tenant, and preserve its data.
- [Contribute to Drift](./contributing.md) — prepare changes, run verification, and open a pull request.
- [Release Drift](./release.md) — publish a verified multi-architecture container image to GHCR.
- [Implement a storage adapter](./storage-adapter.md) — add a persistence bridge without moving domain behavior out of the core.
